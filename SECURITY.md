# Security policy

This is a static, client-side-only portfolio. It has no backend, no forms that submit data, no cookies, no analytics and no third-party requests.

If you find a real vulnerability (XSS, CSP bypass, supply-chain issue, anything), please email **gvhariharan03@gmail.com**. I will reply within a few days and credit you if you want.

The "attacks" in the terminal are simulated. Please do not test against GitHub's or Vercel's infrastructure.
